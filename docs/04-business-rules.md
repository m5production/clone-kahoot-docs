# 4. Бизнес-правила

## Аккаунты

| ID | Правило |
|---|---|
| BR-1 | Никнейм идентифицирует пользователя и должен быть уникальным во всей системе без учёта регистра. |
| BR-2 | Вход и регистрация — отдельные операции; вход с незарегистрированным никнеймом отклоняется. |
| BR-3 | Вход отклоняется одинаковой ошибкой и на неизвестный никнейм, и на неверный пароль. |
| BR-4 | Любой пользователь может быть и ведущим, и игроком; отдельного аккаунта администратора нет. |
| BR-40 | Никнейм: от 3 до 20 символов, пробелы по краям обрезаются, уникален без учёта регистра **(по умолчанию)**. |
| BR-41 | Пароль: не короче 8 символов **(по умолчанию)**. Хранится только хеш пароля. |
| BR-42 | Сессия входа действует 30 дней **(по умолчанию)**; выход завершает её на сервере. |
| BR-83 | Вход и регистрация — отдельные операции на отдельных страницах. Вход не создаёт аккаунт; успешная регистрация сразу выполняет вход. |
| BR-84 | Вход отклоняется одинаковой ошибкой и для неизвестного никнейма, и для неверного пароля, не раскрывая, что именно неверно. |
| BR-85 | Гость видит приветственный экран с описанием продукта. Все страницы, кроме приветственного экрана, входа и регистрации, требуют входа. |

## Квизы и вопросы

| ID | Правило |
|---|---|
| BR-10 | Квиз принадлежит пользователю, который его создал (ведущему). |
| BR-11 | Квиз состоит из нуля или более вопросов. Вопросы показываются в порядке хранения. |
| BR-12 | У вопроса есть текст (обязателен для сохранения), необязательная ссылка на картинку и хотя бы один принимаемый ответ. |
| BR-13 | Принимаемые ответы вопроса сохраняются целым набором: сохранение заменяет все прежние принимаемые ответы. |
| BR-14 | Удаление вопроса удаляет его принимаемые ответы. |

## Живая игра

| ID | Правило |
|---|---|
| BR-20 | На сервере одновременно может идти только одна живая игра. Запуск второй отклоняется с сообщением «The game is already running». |
| BR-21 | При запуске живой игры активен первый вопрос квиза. |
| BR-22 | Ведущий решает, какой вопрос активен, и может возвращаться к прошлым вопросам. |
| BR-23 | Игроки могут подключиться в любой момент, пока идёт игра, в том числе после первых вопросов. |
| BR-24 | Пользователь добавляется в игру один раз; повторное подключение игнорируется. |
| BR-25 | Отключившийся игрок удаляется из игры вместе со своими ответами. |
| BR-26 | Когда ведущий отключается или останавливает игру, игра заканчивается для всех, а её состояние удаляется. Результаты не сохраняются. |

## Ответы и подсчёт очков

| ID | Правило |
|---|---|
| BR-30 | Игрок отвечает, вводя произвольный текст. Пустой ответ не принимается. |
| BR-31 | Игрок даёт один ответ на вопрос. После отправки ответ изменить нельзя. |
| BR-32 | Ответ **верный**, если он точно совпадает с одним из принимаемых ответов вопроса. Сравнение учитывает регистр и пробелы: `Paris`, `paris` и `Paris ` — три разных ответа. |
| BR-33 | Если игрок не ответил на вопрос, вопрос засчитывается как неверный. |
| BR-34 | Ответы на вопрос показываются всем только после нажатия ведущим «Show answers». |
| BR-35 | Очки игрока — это число правильных ответов. Бонуса за скорость и штрафа за неверные ответы нет. |
| BR-36 | В таблице победителей игроки отсортированы по очкам, от большего к меньшему. Порядок игроков с равными очками не определён. |

## Решения владельца продукта

Правила выше описывают текущий код. Открытые вопросы по ним владелец продукта закрыл 18.11.2026; решения по разделению входа и регистрации и по отказу от PIN-кода приняты 20.11.2026. Правила для версии 1.0 — в [целевых требованиях](09-target-requirements.md#95-новые-бизнес-правила).

| Вопрос | Решение | Что меняется |
|---|---|---|
| Игнорировать ли регистр и пробелы по краям при сравнении ответов? | Да | BR-32 → [BR-64](09-target-requirements.md#вопрос-ответ-и-таймер) |
| Могут ли опоздавшие отвечать на прошлые вопросы? | Нет: только текущий и следующие, за пропущенные 0 очков | BR-22, BR-23 → [BR-57, BR-60](09-target-requirements.md#сеанс-игры) |
| Как ранжировать игроков с равными очками? | Выше тот, кто отвечал быстрее | BR-36 → [BR-72](09-target-requirements.md#очки-и-победители) |
| Сохранять ли ответы при коротком отключении? | Да, игрок возвращается в игру | BR-25 → [BR-58](09-target-requirements.md#сеанс-игры) |
| Сохранять ли результаты игр? | Да, ведущий видит историю | BR-26 → [BR-80–BR-82](09-target-requirements.md#история-игр) |
| Разделять ли вход и регистрацию? | Да: приветственный экран и отдельные страницы; вход не создаёт аккаунт | BR-2, BR-3 → [BR-83–BR-85](09-target-requirements.md#аккаунты-и-доступ) |
| Нужен ли PIN-код для входа в игру? | Нет: только ссылка-приглашение и QR-код | BR-52, BR-53 → [BR-52, BR-53](09-target-requirements.md#сеанс-игры) |
